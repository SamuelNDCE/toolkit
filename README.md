# sam-toolkit

An index of tools and automation built around [Claude Code](https://claude.com/claude-code) — coding agent skills, a Discord ops bot, a voice-assistant engine, and assorted small automation scripts.

| Repo | What it is |
|------|------------|
| [sam-agent-skills-library](https://github.com/SamuelNDCE/sam-agent-skills-library) | 276 Claude Code Skills covering software engineering, AI-engineering patterns, DevOps, and workflow automation. |
| [sam-discord-ops-bot](https://github.com/SamuelNDCE/sam-discord-ops-bot) | Discord "ops hub" bot: Shopify watchers, Meta ads monitoring/auto-posting, Netlify deploys, team todo list, email support bridge. Fully env-configurable. |
| [sam-jarvis-assistant](https://github.com/SamuelNDCE/sam-jarvis-assistant) | On-device voice-assistant engine in Rust — wake word, whisper.cpp STT, piper TTS, Claude API reasoning loop. |
| [sam-misc-tools](https://github.com/SamuelNDCE/sam-misc-tools) | Small single-purpose tools: a Composio agent, lead-mapping scripts, a video-episode pipeline, SVG utilities. |

Each repo is independent and can be used on its own — this one is just the map.
